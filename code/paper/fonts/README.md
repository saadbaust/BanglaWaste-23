# Fonts for the figures

`LMRomanPaper-*.ttf` are TrueType conversions of **Latin Modern Roman 10** (the LaTeX font used by the manuscript),
renamed "LM Roman Paper" so they do not clash with an installed Latin Modern. They are loaded by `../waste_figstyle.py`
and embedded in every figure PDF, so the figure text matches the paper text.

Latin Modern is distributed under the GUST Font License (https://www.gust.org.pl/projects/e-foundry/licenses);
modified versions must use a different name, which these do.
